Unity Sprite Editor slicing (Grid By Cell Size)
Atlas size: 2048x2048
Cell Size (px): 400x600
Spacing (px): 2
Offset/Margins (px): 8
Columns: 5
Rows: computed automatically per atlas

Советы:
- В Inspector у атласа поставьте Texture Type = Sprite (2D and UI).
- Sprite Mode = Multiple.
- Sprite Editor → Slice → Type = Grid By Cell Size.
- Width = 400, Height = 600.
- Padding = 2 (Horizontal/Vertical), Offset = 8.
- Порядок заполнения: слева-направо, сверху-вниз.
